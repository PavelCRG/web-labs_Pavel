# Памятка: PHP лабораторные дома и в колледже

Проекты лежат в `php/lab-02` … `php/lab-07`. OpenServer открывает их по доменам `lab-02.local` … `lab-07.local`. Папка `php` добавляется в OpenServer один раз на каждом компьютере; после Git обновлений путь менять не нужно.

> В текущем наборе есть лабораторные 2–7. Папки `lab-01` пока нет, потому что её файлов не было в присланных архивах.

## 0. Один раз опубликовать подготовленную структуру

Сейчас новая структура находится в этой рабочей копии. Чтобы получить её дома и в колледже, сначала отправь её в GitHub. В корне репозитория открой терминал и выполни:

```powershell
git add README.md openserver-instruction.md php materials
git commit -m "Organize PHP labs for Open Server"
git push origin main
```

Это отправит переименованные проекты и инструкцию в GitHub, чтобы колледж получил ту же версию. Если Git сообщит, что нечего коммитить, значит изменения уже сохранены.

## 1. Настройка OpenServer дома

### Добавить папку с проектами

1. Запусти Open Server Panel.
2. Открой меню панели и нажми **Настройки**.
3. Останься на вкладке **Программа**. Внизу слева найди поле **Каталоги для поиска проектов (через «;»)**. На присланном скриншоте в нём указано `{root_dir}\home`.
4. Не удаляя `{root_dir}\home`, допиши после точки с запятой путь к папке `php` этого репозитория. Для текущей папки дома значение будет:

   ```text
   {root_dir}\home;D:\Разработка колледж web html\web-labs_Pavel\php
   ```

   В поле указывается именно `php`, где находятся `lab-02`, `lab-03` и остальные папки.
5. Нажми **Сохранить и перезапустить** внизу окна.

Путь можно посмотреть в Проводнике: открой папку репозитория и скопируй адрес папки `php`. Если репозиторий дома лежит в другом месте, используй его фактический путь.

### Первый запуск

1. В списке проектов нажми стрелку справа от `lab-02.local`.
2. Убедись, что в подменю указаны **HTTP: Apache** и **PHP: 8.5**. Если указаны другие значения, выбери нужный пункт во вложенном меню.
3. Нажми **Открыть в браузере**.
4. Проверь страницу. В лабораторной 2 нет `index.php` в корне, поэтому для проверки задания открой `http://lab-02.local/task1.php`.

В меню на присланном скриншоте компоненты Apache и PHP 8.5 уже отмечены зелёными значками. Красный значок у домена — отдельная индикация статуса проекта; сам по себе он не показывает, какая именно ошибка. OpenServer подтверждает, что значки проектов меняются в зависимости от статуса. [Open Server Panel 6](https://github.com/OSPanel/OpenServerPanel/discussions/27)

## 2. Настройка OpenServer в колледже

### Получить копию репозитория

1. Сначала отправь изменения с домашнего компьютера командами из раздела **Обновить репозиторий**.
2. В колледже один раз открой терминал и выполни команду клонирования:

   ```text
   git clone https://github.com/PavelCRG/web-labs_Pavel.git C:\OSPanel\home\web-labs-pavel
   ```

   Это создаст папку `C:\OSPanel\home\web-labs-pavel`. Если OpenServer установлен на другом диске, укажи удобный локальный путь без кириллицы.

3. Запусти OpenServer и открой **Настройки → Программа**.
4. В поле **Каталоги для поиска проектов (через «;»)** сохрани `{root_dir}\home` и допиши путь к клону:

   ```text
   {root_dir}\home;C:\OSPanel\home\web-labs-pavel\php
   ```

5. Нажми **Сохранить и перезапустить**.
6. Открой меню нужного `lab-XX.local`, проверь **HTTP: Apache** и **PHP: 8.5**, затем нажми **Открыть в браузере**.

На каждом компьютере путь в настройках свой: дома — к домашней копии, в колледже — к копии в колледже. В OpenServer указывай именно ту копию, в которой будешь работать. Не создавай вторую рабочую копию: иначе можно обновить одну папку, а запускать другую.

## 3. Каждый день

### Начинаешь работу

1. В папке репозитория открой терминал и выполни `git pull origin main`, чтобы получить последние изменения.
2. Запусти OpenServer.
3. Открой меню нужного `lab-XX.local` и проверь **HTTP: Apache** и **PHP: 8.5**.
4. Нажми **Открыть в браузере**.

### Заканчиваешь работу

1. Сохрани файлы в папке репозитория.
2. Отправь изменения в GitHub командами из раздела **Обновить репозиторий**.
3. Переносить папку проекта вручную между домом и колледжем не нужно.

## 4. Обновить репозиторий между компьютерами

Перед началом работы на компьютере забери последние изменения:

```powershell
git pull origin main
```

После своей работы сохрани и отправь изменения. Перед `commit` проверь список файлов командой `git status`:

```powershell
git add -A
git commit -m "Update PHP labs"
git push origin main
```

Если работал в колледже — отправь изменения там, а дома сначала выполни `git pull origin main`. Если работал дома — порядок обратный. Не редактируй одни и те же файлы одновременно на двух компьютерах; сначала отправляй изменения с одного и забирай их на другом.

После обычного `pull` код лабораторных обновится в той же папке, а настройки поиска OpenServer останутся прежними. Если обновление добавило новую лабораторную или изменило `.osp/project.ini`, перезапусти OpenServer, чтобы он перечитал настройки. После обновления обычного PHP-файла достаточно обновить страницу в браузере.

## Если лабораторные не появились

1. Проверь, что добавлен путь до папки `php`, а не до корня репозитория или отдельной `lab-*` папки.
2. Нажми **Сохранить и перезапустить** ещё раз.
3. Если браузер пишет `ERR_NAME_NOT_RESOLVED`, открой **Настройки → Файл HOSTS** и проверь, включено ли использование HOSTS. При проверке файла Windows записей для `lab-02.local` … `lab-07.local` я не нашёл; если их нет и у тебя, OpenServer не зарегистрировал локальные домены. Не добавляй записи вручную — сначала проверь журнал OpenServer и доступ к HOSTS.
4. Проверь наличие PHP 8.5: все шесть проектов настроены на эту версию.
5. Если путь с пробелами или кириллицей не принимается, размести копию репозитория в короткой папке без них, например `C:\OSPanel\home\web-labs-pavel`, и добавь её `php`.

Настройка каталога поиска находится в **Настройки → Программа → Каталоги для поиска проектов**. [Подтверждение OpenServer](https://github.com/OSPanel/OpenServerPanel/discussions/265)
