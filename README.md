# Веб лабораторные

Общий репозиторий лабораторных. Сейчас здесь PHP; для следующих языков добавляются отдельные папки на верхнем уровне.

## Структура

```text
web-labs_Pavel/
├─ php/                         проекты для Open Server Panel
│  ├─ lab-02/                   лабораторная 2
│  ├─ lab-03/                   лабораторная 3
│  ├─ lab-04/                   лабораторная 4
│  ├─ lab-05/                   лабораторная 5
│  ├─ lab-06/                   лабораторная 6
│  └─ lab-07/                   лабораторная 7
├─ materials/
│  └─ php/                      условия и теория
│     ├─ lab-06/
│     ├─ lab-07/
│     └─ lab-08/
├─ openserver-instruction.md  отдельная инструкция по OpenServer
└─ README.md
```

В каждой папке `php/lab-*` лежит самостоятельный проект с настройками в `.osp/project.ini`. Папки названы одинаково; домены проектов — `lab-02.local` … `lab-07.local`.

## Open Server Panel

Отдельная инструкция с шагами по меню и запуску: [openserver-instruction.md](openserver-instruction.md). Настройку поиска проектов нужно сделать один раз на каждом компьютере.

## Ежедневная работа

1. В своей копии репозитория выполни `git pull origin main`.
2. В меню нужного проекта проверь, что указаны **HTTP: Apache** и **PHP: 8.5**.
3. Выбери **Открыть в браузере** в меню проекта.
4. После работы отправь изменения в GitHub командами `git add -A`, `git commit`, `git push`.

Первоначальная настройка дома и в колледже, путь в настройках OpenServer и полный порядок обновления описаны в [отдельной инструкции](openserver-instruction.md).

Видео из исходного архива не добавлены: они занимают около 376 МБ. PDF и DOCX с условиями сохранены в `materials/php`.
